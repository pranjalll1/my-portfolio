# Pranjal Soni — Developer Portfolio

Personalized from the supplied portfolio starter while retaining its cinematic dark theme, animated sections, navigation, and interactive project/certificate cards.

## Personalization
- Name, contact links, CV and education updated to Pranjal Soni's supplied CV.
- Skills and projects limited to information in the supplied CV.
- Four supplied certificates added to `public/certificates/` and `data/certificates.json`.
- Unverified template achievements and coding-platform metrics removed/replaced with CV-listed milestones.
- No personal photo: hero/about use a PS initials visual.
- CV available at `/resume.pdf`.

## Run locally
Requires Node.js 20+.
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Build
```bash
npm run build
```

## Important
Project-specific GitHub repository URLs were not supplied, so project cards currently link to the GitHub profile where a repository link was unavailable. Update `data/projects.json` with each exact repository URL when available. The Advanced Bug Tracker live demo is linked to the URL supplied by the owner.
